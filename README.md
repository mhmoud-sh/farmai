# FarmAI
A livestock management app for dairy, beef, sheep, and poultry farms.

## Setup
- Clone repo: `git clone https://github.com/your-username/farmai.git`
- Backend: `cd backend && npm install`
- Frontend: `cd frontend && npm install`

## Tech Stack
- Backend: Node.js, Express, PostgreSQL
- Frontend: React, Material-UI
- AI: Python, Flask
